Business Requirement

Enable a fully digital personal-loan journey from application creation through disbursement.

Process

Application → KYC → Credit Bureau → Fraud/PEP → BRE Decision → Documents → E-Sign → E-Mandate → Disbursement

Business Rules

• KYC must be verified before credit processing.
• Credit score must meet the configured eligibility threshold.
• Fraud/PEP checks must return clear status.
• Documents, E-Sign and E-Mandate must be completed before disbursement.

API / Integration Mapping

KYC API → Identity verification
CIBIL API → Credit score
Fraud/PEP API → Risk screening
BRE → Eligibility decision
E-Sign API → Digital agreement
E-Mandate API → Repayment mandate
Disbursement API → Loan payout

Exception Handling

Example: CIBIL timeout → preserve application state → record integration failure → mark retryable → retry integration → continue processing after successful response.

UAT Scenario

Given a valid applicant with successful KYC, CIBIL and fraud checks, when the BRE evaluates the application, then an eligible application should proceed to approval and subsequent fulfilment stages.

Audit / Traceability

Every major status transition and integration event is recorded with timestamp, previous status, new status and processing details.
